# Nasi Tempong By SUNDA

Next.js App Router, React, TypeScript, Tailwind CSS v4, Lucide icons, and Motion.

## Run

`npm install` then `npm run dev`. Production: `npm run build` generates the static site in `out/`.

## Business content

Edit `app/site-data.ts` to set the verified WhatsApp number (international digits, e.g. 62…), actual menu prices, and catering offers. WhatsApp links automatically include the selected dish, quantity, spice level, and estimated total. Until a number is provided, the flow offers a copyable order and the supplied Maps profile.

The name and address come from the user-provided Google Maps link. Hours, facilities, Google rating and customer reviews were not verified. The site links to real Maps reviews instead of asserting an unverified rating. Prices, catering packages and testimonial examples are explicitly marked as illustrative. Generated photography is illustrative; replace with restaurant photographs when available. Confirm the proposed H−2 catering lead time before public launch.

## Design

Warm cream #FAF7F2, chili red #9E2A2B, dark olive and espresso. Playfair Display and DM Sans. Responsive layouts, keyboard tabs, accessible order dialog, reduced-motion support, and a safe-area-aware mobile action dock.
